# 工程升级记录 · 2026-10-10

## 已实现

- Router 使用部署前缀与意图预加载，Query 默认一分钟新鲜期，避免不必要的重复请求。
- 八页静态预渲染覆盖 3D 路由，错误页回首页遵循部署前缀，页面语言改为中文。
- 3D 查看器进入视口附近才加载；共享脚本加载 Promise，失败可重试，源码变更与卸载安全清理；使用 DOM 属性替代 HTML 字符串，增加加载与失败提示。
- 粒子与光球在隐藏标签页、离开视口时暂停，刷新上限约 30 fps；减少动态效果偏好会禁用持续动画。樱花布局使用确定性数据，避免服务端/客户端随机样式不一致。标题动画保留 React 文本节点并清理动画，滚动展示清理监听器。
- API 统一 JSON 响应与禁止缓存，按实际字节限制请求体；拒绝空白、非字符串字段、评分特殊键名与非整数评分。
- AI 消息仅接受 user/assistant 角色及有限长度，输出主题只保留允许的 CSS 字段；上游请求包含重试总计 12 秒期限，只对瞬时状态重试。
- npm 锁文件、TypeScript 检查、Node 测试与静态产物验证加入 PR/部署流水线；PR 不部署。

## 新增管理后台

`src/routes/admin.tsx` 与 `functions/api/admin.js` 提供按分类读取/导出/删除。服务端对 Bearer 令牌进行摘要与定长比较，未配置或过短令牌时关闭接口。记录使用内容摘要标识，读取后发生变化的记录拒绝删除，避免按数组索引误删；这不是 KV 并发事务。没有用户账号系统、角色权限、审计持久化或自动数据恢复。管理页不进入公开导航，并标记 noindex；安全依赖接口认证。

## 调情专区

## AI 配置与互动

- 新增 AIChat 真实请求、最近对话窗口、发送状态、失败提示和清空；仅内存保存。
- 新增 AISettings 与受保护的配置 API，管理角色提示词、模型、互动开关和 Key。
- 后台 Key 使用独立服务端秘密进行 AES-GCM 加密，配置读取只返回是否配置；删除后可回退环境 Key。
- 增加密文存储、服务端解密、不回显、缺少加密秘密拒绝保存、禁用互动和删除 Key 回退测试。
- 移除先前添加的 BDSM 说明和套话文案；默认文字简短，角色与称呼可配置。

## 全站文案管理

通过公开文案 API、共享纯文本替换运行时和后台 ContentEditor 覆盖 React 页面及旧版 HTML 页面。React 页面等待客户端加载完成后应用替换，标题动画不再重建 React 管理的子节点；普通表单输入和用户投稿保持原样。替换仅写入文本节点及 placeholder/title/alt/aria-label 等文案属性，不执行 HTML、脚本，也不改链接目标。

已提供搜索/分类、手动添加、草稿预览、发布、空白隐藏、单项/全站默认恢复、JSON 导入导出、发布前备份、历史恢复及历史分页。发布时检查已读取版本，备份失败则拒绝发布；KV 的并发一致性限制仍需遵守。
